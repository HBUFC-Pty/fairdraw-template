# UK GDPR and PECR documents

> **Template, not legal advice.** Have every document here reviewed by a qualified solicitor or data protection
> adviser before you rely on it.

These documents reuse published, openly licensed texts where suitable ones exist, adjusted for UK GDPR, the ICO and
what this template actually does. Each adapted document carries its own credit and licence notice, and
`docs/legal/SOURCES.md` records where every passage came from. Document licences (CC BY-SA 4.0, CC BY 4.0, the Open
Government Licence v3.0) are separate from the template's code licence (CPAL-1.0).

| File | What it is | Based on |
| --- | --- | --- |
| [privacy-notice.md](privacy-notice.md) | The answers to give the ICO's free privacy notice generator, derived from the code | ICO generator (no text copied) |
| [content/privacy.md](../../content/privacy.md) | What the site's `/privacy` page shows: a placeholder for the generator's output, plus cookies, entry lists, draw records, winners and age checks | Own wording |
| [cookie-statement.md](cookie-statement.md) | The cookie statement, and what changes if you add analytics | Automattic Legalmattic, CC BY-SA 4.0 (so this file is CC BY-SA 4.0) |
| [retention.md](retention.md) | Retention policy and the schedule the code enforces | 37signals policies, CC BY 4.0 |
| [dsar-procedure.md](dsar-procedure.md) | Handling subject access and other rights requests | 37signals policies, CC BY 4.0; ICO guidance structure |
| [breach-procedure.md](breach-procedure.md) | Personal data breach procedure (72 hours to the ICO) | ICO guide, Open Government Licence v3.0 |
| [ropa-template.md](ropa-template.md) | Record of processing activities (Article 30) | Own wording |
| [dpia-template.md](dpia-template.md) | Data protection impact assessment | Own wording, ICO step structure |

Before launch: register with the ICO and pay the data protection fee, make your privacy notice with the ICO generator
(see `privacy-notice.md`), fill in every placeholder, and complete the ROPA and DPIA for your actual set-up (hosting
provider, email provider, payment processor).
